## 2. 🔴 缺"它现在在服役"——项目最硬的事实

**位置**：建议新增一节，插在 §是什么 之后（`README.md:14` 之后）

**为什么重要**：README 通篇是架构、边界、原则，**没有一句说"它已经在跑"**。而这是最能证明项目成立的事实。

**建议新增内容**（数字都有出处）：

```markdown
## 它现在在服役

PPM 不是"待集成的库"——**它已经是 RoboMind-S3（ESP32-S3）上真实运行的感知组件**。

```
OV5640 取帧 → ppm_run()  → 决策结论 → 编码成 11 字段消息 → 推给 PC 端显示
              ↑
        PPM 负责这一段
```

| 事实 | 数据 | 出处 |
|---|---|---|
| 真机连续跑批 | **400 帧 `ok=400 run_fail=0 encode_fail=0 fb_null=0`** | `RoboMind-S3/docs/logs/u02b-pipeline-on-2026-11-13.log:520` |
| 无人场景跑批 | 300 帧 `ok=300 run_fail=0`（`no_target=300`） | `RoboMind-S3/docs/logs/u02b-noface-frames-2026-11-13.log:414` |
| 调用频率 | **约 105 ms 一次**（≈9.5 fps） | 见下方注 |
| 动态堆 | **≈ 0**（PPM 主体走静态池，见 `PPMI_MAX_CTX`） | — |

> **关于 105 ms**：`ppm_producer` 里声明的是 `kPeriodMs = 70`，但**实际周期约 105 ms**——
> `esp_camera_fb_get()` 本身要等一帧（~105 ms），`vTaskDelayUntil` 因此一直在空转、不再是节拍源。
> 交叉印证：PC 端 `RoboMind-Console` 实测 **`fps=9.47`** ⇒ `1000/9.47 = 105.6 ms`，两侧一致。
```

> **为什么这个数要写准**：如果写"70 ms / 14 fps"，任何人对一下 PC 端的 `fps=9.47` 就会认为**其中一方在说谎**。写 105 ms 并解释原因，反而展示了"我们知道偏差从哪来"。

## 5. 🟡 缺 §已知限制——两条消费方必须知道的 ABI 事实

**位置**：建议新增一节，放在 §不是什么 之后

**为什么必须有**：这两条会让误用者拿到"看起来正常、实际错误"的数据，而 README 现在一个字都没提。

```markdown
## 已知限制（消费方必读）

### `absent_100ms` 放在每目标里，无目标帧不可用

`absent_100ms`（"人离开多久"）是**全局状态**，但它定义在 `ppm_target_t`（**每目标**）里。
⇒ **没有目标时读不到** ⇒ 消费方只能拿到 `0`，而 `0` 在这里不是"刚离开"，是"不可知"
（人可能已经离开 20 分钟）。

| 消费方要做的事 | 正确做法 |
|---|---|
| 判断"人是否离开" | 用 `result.degrade` 的 `PPM_DEGRADE_NO_FACE` 位 + 帧间隔自行推算，**不要用 `absent_100ms`** |

> 这是**契约层的层错配**（全局状态放在每目标结构里），不是实现 bug。
> 修法建议：在 `ppm_result_t` 顶层加一个全局 `absent_100ms`，与 `targets[]` 解耦（一次 ABI minor）。

### 静态池：`PPMI_MAX_CTX = 4`，`g_pool` 约 30 KB

`PPMI_MAX_CTX = 4`（`src/core/ppm_core.h:45`）⇒ 静态池 `g_pool` = **30,688 B**，
占整个 PPM 静态 RAM（46,911 B）的 **65%**。

| 事实 | 数值 |
|---|---|
| `g_pool[4]` | **30,688 B**（每个 ctx 7,672 B） |
| PPM 静态 RAM 合计 | **46,911 B** |
| **4 → 1 可省** | **23,016 B**（精确：`30,688 − 7,672`） |

> 单目标场景下 1 个 ctx 就够，但 `PPMI_MAX_CTX` 是**裸 `#define`、无 `#ifndef` 保护**
> ⇒ 产品侧无法用 `-D` 覆盖，必须改 PPM 源文件。
```

> **出处**：`src/core/ppm.h` / `ppm_core.h:45`；静态池数值来自 RoboMind-S3 的 map 与 `nm` 实测（`libppm.a` `.bss` 46,895 + `.data` 16）
